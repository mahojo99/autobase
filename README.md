# Relay

A local desktop workspace where you talk to an orchestrator that sets up bots, delegates tasks, and brings the results together.

Relay is a working name for an independent portfolio experiment. It is not an announced commercial product or a finished application.

## Current status

Product requirements and the implementation brief are prepared. Application implementation and verification are pending.

- [Product requirements](docs/PRD.md)
- [Astra implementation prompt](docs/BUILD-PROMPT.md)
- [Technical references](docs/REFERENCES.md)

The first implementation targets Windows with Electron, React, TypeScript, SQLite, a Codex adapter, and a Claude Agent SDK adapter. Availability depends on each engine's prerequisites and authentication. An optional local virtual computer follows the core task and orchestration workflow.
